Planteo del problema

Clasificación de empresas

Pregunta: ¿se puede anticipar si una empresa entrará en crisis a partir de sus ratios contables?

  • Grupos conocidos (variable CONDICIO): fallido y normal (50 empresas, 25 por grupo).
  • Predictoras: ratios económico-financieros del balance.
  • Regla de asignación para dos grupos con matrices de covarianzas iguales:

\[L(\mathbf{x})=(\bar{\mathbf{x}}_1-\bar{\mathbf{x}}_2)'\mathbf{S}_p^{-1}\mathbf{x}-\tfrac12(\bar{\mathbf{x}}_1-\bar{\mathbf{x}}_2)'\mathbf{S}_p^{-1}(\bar{\mathbf{x}}_1+\bar{\mathbf{x}}_2)\;\ge\;\ln\frac{\pi_2}{\pi_1}\]

Plan: explorar \(\rightarrow\) verificar supuestos \(\rightarrow\) discriminante canónico \(\rightarrow\) selección de variables \(\rightarrow\) transformar \(\rightarrow\) lineal, cuadrático y regularizado \(\rightarrow\) comparar.

Discriminante canónico

Construcción paso a paso

\(\mathbf{T}=\mathbf{W}+\mathbf{B}\), con \(\mathbf{W}=\sum_g (n_g-1)\mathbf{S}_g\) y \(\mathbf{S}_p=\mathbf{W}/(n-G)\).

La dirección discriminante \(\mathbf{u}\) maximiza \(\dfrac{\mathbf{u}'\mathbf{B}\mathbf{u}}{\mathbf{u}'\mathbf{W}\mathbf{u}}\): es el autovector de \(\mathbf{W}^{-1}\mathbf{B}\) asociado al mayor autovalor.

discriminante_canonico <- function(X, grupo) {
  X <- as.matrix(X); n <- nrow(X); g <- nlevels(grupo)
  centrar <- function(M) scale(M, scale = FALSE)
  W  <- Reduce(`+`, lapply(levels(grupo), function(k)
          crossprod(centrar(X[grupo == k, , drop = FALSE]))))
  Tt <- crossprod(centrar(X))
  B  <- Tt - W
  e  <- eigen(solve(W, B))                       # W^{-1} B
  u  <- Re(e$vectors[, 1])
  z  <- drop(X %*% u)                            # puntajes discriminantes
  cent <- tapply(z, grupo, mean)                 # centroides
  # asignación: centroide más cercano (no depende del signo de u)
  pred <- factor(levels(grupo)[apply(abs(outer(z, as.numeric(cent), "-")), 1, which.min)],
                 levels = levels(grupo))
  list(W = W, B = B, Sp = W / (n - g), autovalores = Re(e$values),
       u = u, z = z, centroides = cent, pred = pred)
}

canon <- discriminante_canonico(datos[vars4], datos$CONDICIO)

Selección de variables

Con el estadístico F parcial (10 variables)

Para dos grupos, el aporte de la variable \(i\) dado el resto se contrasta con \[F_i=\frac{(n-p-1)\,\frac{n_1n_2}{n}}{(n-2)+\frac{n_1n_2}{n}D_p^2}\cdot\frac{b_i^2}{(n-2)\,t^{ii}}\;\sim\;F_{1,\,n-p-1}\]

f_parcial <- function(X, grupo) {
  X <- as.matrix(X); n <- nrow(X); p <- ncol(X)
  idx <- split(seq_len(n), grupo)
  n1 <- length(idx[[1]]); n2 <- length(idx[[2]])
  dm <- colMeans(X[idx[[1]], ]) - colMeans(X[idx[[2]], ])
  W  <- Reduce(`+`, lapply(idx, function(i) crossprod(scale(X[i, ], scale = FALSE))))
  iSp <- solve(W / (n - 2))
  b   <- drop(iSp %*% dm)                      # coeficientes de la función lineal
  mah <- drop(dm %*% iSp %*% dm)               # Mahalanobis^2 entre medias
  f3  <- ((n - p - 1) * n1 * n2 / n) / ((n - 2) + n1 * n2 * mah / n)
  iT  <- solve(crossprod(scale(X, scale = FALSE)))
  Fi  <- f3 * b^2 / ((n - 2) * diag(iT))
  Fc  <- qf(0.95, 1, n - p - 1)
  data.frame(variable = colnames(X), coeficiente = b, F = Fi,
             F_critico = Fc, aporta = Fi > Fc)
}

Las funciones discriminantes “a mano”

Lineal: \(L(\mathbf{x})=a+\mathbf{b}'\mathbf{x}\) con \(\mathbf{b}=\mathbf{S}_p^{-1}(\bar{\mathbf{x}}_1-\bar{\mathbf{x}}_2)\).

Cuadrática: \(Q(\mathbf{x})=a+\mathbf{b}'\mathbf{x}+\mathbf{x}'\mathbf{C}\mathbf{x}\), con \(a_i=-\tfrac12\left(\bar{\mathbf{x}}_i'\mathbf{S}_i^{-1}\bar{\mathbf{x}}_i+\ln|\mathbf{S}_i|\right)\), \(\mathbf{b}_i=\mathbf{S}_i^{-1}\bar{\mathbf{x}}_i\) y \(\mathbf{C}_i=-\tfrac12\mathbf{S}_i^{-1}\) (se restan los del grupo 2 a los del grupo 1).

coef_discriminantes <- function(X, grupo) {
  X <- as.matrix(X); n <- nrow(X)
  ix <- split(seq_len(n), grupo)
  m  <- lapply(ix, function(i) colMeans(X[i, ]))
  S  <- lapply(ix, function(i) cov(X[i, ]))
  Sp <- Reduce(`+`, Map(function(i, Sk) (length(i) - 1) * Sk, ix, S)) / (n - length(ix))
  iSp <- solve(Sp)
  lineal <- list(a = -0.5 * drop((m[[1]] - m[[2]]) %*% iSp %*% (m[[1]] + m[[2]])),
                 b = drop(iSp %*% (m[[1]] - m[[2]])))
  una <- function(mk, Sk) list(
    a = -0.5 * (drop(mk %*% solve(Sk) %*% mk) + log(det(Sk))),   # log|S|, no |S^-1|
    b = drop(solve(Sk) %*% mk),
    C = -0.5 * solve(Sk))
  q1 <- una(m[[1]], S[[1]]); q2 <- una(m[[2]], S[[2]])
  cuad <- list(a = q1$a - q2$a, b = q1$b - q2$b, C = q1$C - q2$C)
  list(lineal = lineal, cuad = cuad)
}

Discriminante regularizado (Friedman)

\(\lambda\) contrae cada \(\mathbf{S}_i\) hacia \(\mathbf{S}_p\) (\(\lambda=0\): cuadrático; \(\lambda=1\): lineal) y \(\gamma\) hacia un múltiplo de la identidad.

fijar <- function(l, gm) {
  m <- rda(CONDICIO ~ ., data = dat_fun, lambda = l, gamma = gm, crossval = TRUE)
  c(lambda = l, gamma = gm, error_cv = unname(m$error.rate["crossval"]))
}
